Two controls stand between a Digital Employee and an effect. The action gateway fails closed: a deployment ceiling no tenant can widen, unknown actions, tenant deny lists, channel membership (modelled here as workspace membership), secret markers and a size cap, in that order. The approval gate holds an assignment before any external effect for any of four reasons; only a person can decide, once, and each request names and records the role required to decide it.
